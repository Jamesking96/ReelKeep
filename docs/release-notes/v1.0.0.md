The first release of **ReelKeep** — get your videos back as files you own when the online copy is the only one left.

### Download

**`ReelKeep.exe`** below is the whole app: one self-contained file, no installer and no .NET install needed.
Windows 10 / 11 (64-bit). On first start it fetches the open-source tools it uses (yt-dlp and FFmpeg) into
`%LOCALAPPDATA%\ReelKeep\tools`.

> The exe isn't code-signed, so Windows SmartScreen may show a warning the first time — choose **More info › Run anyway**.
> `ReelKeep.exe.sha256` lets you check the download is intact.

### What's in 1.0.0

- Paste a link, several links or a whole playlist / channel and choose what to keep
- Download queue with up to 6 at a time (Queue › Simultaneous downloads), pause / resume / retry
- Save as video, audio (M4A, MP3, FLAC, WAV) or both, with title, creator and cover art tags
- Library with search, sort, grid / list views, multi-select and a right-click menu
- Built-in player with chapters, mini player and theater mode
- Clips: mark, preview and save as MP4 or audio
- Details panel with Copy details / Copy link (right-click › Details… or Alt+Enter)
- Re-download at a different quality while keeping your clips and audio files
- Rename, delete to the Recycle Bin, show in folder
- Light, dark or follow-Windows theme
