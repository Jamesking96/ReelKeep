**ReelKeep 1.1.0** adds folders to keep your library organised, sign-in for restricted videos, and clearer errors when a download fails.

### Download

**`ReelKeep.exe`** below is the whole app — replace your old copy with it. Your library, settings and tools carry over
as they are. Windows 10 / 11 (64-bit).

> The exe isn't code-signed, so Windows SmartScreen may warn the first time — choose **More info › Run anyway**.
> `ReelKeep.exe.sha256` lets you check the download is intact.

### New

**Folders**
- **Save to folder** for new downloads (in **Options**): type a subfolder like `Music / Chill`, or pick one you already
  have. Folder names can use the naming tokens — `{channel}` gives every creator their own folder.
- *Multiple links* and the playlist picker have their own folder field, and the playlist picker can name the folder
  after the playlist.
- **Move to folder…** in the right-click menu (and the selection bar / Details panel) moves one or many items. Every file
  moves together — video, audio files, clips and thumbnail; name clashes become "Name (2)" instead of overwriting, and
  folders left empty are tidied away.
- A **Folders** section in the sidebar to browse and filter by folder (subfolders included).
- The Details panel and *Copy details* show each item's folder; the Queue shows where each download is going.

**Sign-in for restricted videos**
- New **Sign-in** setting at the bottom of the sidebar for age-restricted or members-only videos: use the account you're
  signed into in a browser (Firefox works best) or a `cookies.txt` file.
- Failed downloads that need an account link straight to it, and the dialog can retry them all once it's set up.

**Clearer errors**
- Failed downloads show a short, plain reason; click it (or **Error**) for the full message and **Copy error**.
- *Copy error* also on the link box and on general error messages.
- Problems reading a browser's sign-in are recognised and explained (browser still open, encrypted cookies, wrong
  browser, bad cookies file).

### Notes

- Existing items stay where they are (in the library folder) until you move them.
- Each item's records stay in the hidden `.library` folder at the top of your library, so libraries keep working if you
  open them with an older version — items in subfolders just won't be found by it.
